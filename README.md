## GitHub Pages

在 Settings → Pages 中选择 GitHub Actions。仓库内的发布流程解压 qin-lineup-lab-github-pages.zip 并发布其中的静态网站。网站使用相对路径，可运行于 GitHub Pages 项目子目录。更新网站时替换发布包并提交即可触发重新发布。

不需要服务器、数据库、访问者登录或 API 密钥。国内直连及微信、QQ 内可用性需实测。
